# Random Password Generator

A simple and user-friendly Random Password Generator built using Python and Tkinter. This application allows users to generate strong and secure passwords based on their preferences.

---

 # Features

- Generate random passwords
- Choose password length
- Include uppercase letters (A-Z)
- Include lowercase letters (a-z)
- Include numbers (0-9)
- Include special symbols (!@#$%^&*)
- Copy generated password to clipboard
- Show/Hide password
- Password strength indicator (Weak, Medium, Strong)
- User-friendly graphical interface (GUI)
- Error handling for invalid inputs

# ▶ How to Run

### 1. Clone the repository

```bash
git clone <repository-link>
```

### 2. Open the project folder

```bash
cd Random Password Generator
```

### 3. Install required packages

```bash
pip install -r requirements.txt
```

### 4. Run the project

```bash
python main.py
```

---

# How to Use

1. Enter the desired password length.
2. Select the character types you want.
3. Click **Generate Password**.
4. View the password strength.
5. Show or hide the password if needed.
6. Click **Copy Password** to copy it to the clipboard.
